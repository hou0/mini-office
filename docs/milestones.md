## 4. 建议后续冲刺

1. **发布工程（1–2 周）**：三平台 bundle、代码签名/公证、自动更新、崩溃报告、LICENSE 审核。
2. **兼容性深化（2–4 周）**：表格跨页拆分、修订/批注面板、页眉页脚编辑、超链接写回。
3. **Excel 深化（2–3 周）**：条件格式渲染、图表保留策略、共享字符串写回、公式引用重排、筛选多列。
4. **PPT 编辑（4–6 周）**：文本/图片移动缩放、备注编辑、切页动画与媒体。
5. **性能/视觉 CI（1–2 周）**：10 万行基准、三平台字体矩阵、Playwright 截图回归。
