# Mini Office 0.1.4

## 本次更新

- 改进 Excel 打印预览：支持预览内切换纵向/横向、缩放和一页宽。
- 修复 Excel 打印中的彩色填充、合并单元格、行高分页和文字清晰度问题。
- 修复 Excel PDF 导出跟随页面方向的问题。
- 修复 Word 打印和 PDF 输出中段落高亮、表格底纹等背景色被抹掉的问题。
