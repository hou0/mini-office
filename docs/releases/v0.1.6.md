# Mini Office 0.1.6

<!-- 功能：汇总 0.1.5 之后 Word 排版补齐、只读预览、纸张配色与一批排版修复；时间：2026-11-01；作者：lq。 -->

0.1.6 包含 0.1.5 之后的全部改动：Word 制表位、标尺与目录三块排版能力补齐，PDF / Markdown / HTML 只读预览，护眼模式与深色纸张配色，内置度量兼容字体，以及一批围绕换行、底纹与打印的修复。

## 新增功能

### Word 制表位

- **四种对齐**：左对齐、居中、右对齐、小数点对齐；前导符支持无、点线、虚线、下划线、中点线与粗线。
- **默认间距**：读写文档级 `w:defaultTabStop`（缺省 720 twips，即 48px / 0.5 英寸），没有自定义制表位时按它等距推进。
- **正文 Tab 结构化**：光标处按 Tab 插入真正的制表符而不是空格，保存为 `w:tab`；表格内 Tab 仍走单元格导航，⇧+Tab 交给焦点切换。
- **读写顺序**：`w:tabs` / `w:tab` 写在 `w:pPr` 的 `w:shd` 之后、`w:spacing` 之前，符合 CT_PPr 顺序，Word 打开不报部件非法。
- **渲染方式**：浏览器无法用 CSS 表达「跳到下一个制表位」，因此先输出零宽占位块，布局完成后实测位置再补宽度与前导符边框；屏幕分页与离屏测量共用同一套函数，分页高度与屏幕显示一致。

### Word 标尺

- **默认隐藏**，与 Word / WPS 的「视图 → 标尺」一致；工具栏按钮、视图菜单、命令面板、设置 → 外观四处可开，开关状态会记住。
- **刻度与边距**：按厘米标注，页面左右页边距用更深底色标出，正文可用宽度一眼可见。
- **缩进拖动**：首行缩进（上方三角）与左缩进（下方方块）分开拖动，右缩进独立；拖动在未缩放坐标系里计算，50% 与 200% 缩放下拖到的是同一个值。
- **制表位操作**：标尺空白处单击新增，拖动调整，双击或拖出标尺删除；整次拖动合并为一条撤销记录。
- **不进入输出**：打印与 PDF 导出永远不包含标尺。

### Word 目录

- **采集规则与 Word 一致**：先看段落大纲级别 `w:outlineLvl`，再看内置样式 ID（`HeadingN` / `标题N`），不依赖自定义样式的显示名，样式改名后目录不会突然变空。
- **实时页码**：页码由分页结果反查，并叠加节的起始页码（`w:pageNumberStart`），增删正文后自动跟随，不需要手动更新域。
- **点击跳转**：目录条目直接跳到对应标题所在页；条目文本取段落纯文本，图片与域占位不计入，制表符归一为空格。
- **写回真正的域**：保存时输出 `fldChar begin` / `instrText " TOC \o "1-N" \h \z \u "` / `separate` / 条目 / `end`，并在 `settings.xml` 写入 `<w:updateFields w:val="true"/>`；打开旧文档时用编辑器实测页码替换过期的域缓存结果。

### Word 表格

- **Office 风格表格手柄**：单击选中整表，拖动把整张表移到目标段落前后。
- **末格定位**：按网格右下角定位，不再取数组最后一项——合并单元格会让数组顺序与视觉顺序不一致。

### 只读预览

- **PDF / Markdown / HTML 直接打开**：注册零依赖的只读处理器，PDF 走浏览器内建渲染，Markdown 与 HTML 解码为文本，不引入大型解析库。
- **统一预览视图**：左预览右设置两栏布局，一页一屏加页码器，Word 打印预览与只读预览共用，与 Office 的打印窗口一致。

### Excel

- **阅读模式**：开启后当前单元格所在行列在网格内叠加浅色参考带，并同时点亮行表头与列表头形成十字参考；关闭后不渲染任何额外节点，打印与导出不包含。
- **单元格格式**：填充色与边框交互调整，公式栏点选/拖选引用保持可用；填充柄外圈改用纸张色描边。

### 外观

- **护眼模式**：标题栏眼睛按钮与 设置 → 外观 均可切换，只切 `data-eyecare`，配色集中在 `tokens.css`（米黄纸色、低蓝光）；切换主题时保留护眼状态；导出 PDF 与打印强制回白纸，交付文件不会被米黄底色污染。
- **内置度量兼容字体**：随包分发 Caladea（Cambria 度量兼容）与 Carlito（Calibri 度量兼容），含许可证文件，西文换行与分页更接近 Word。
- **中文字体回退**：按字形风格（宋 / 黑 / 楷 / 仿宋）回退而不是一律变黑体；华文、方正等厂商别名与基础字体等价，表里没有的字体按名称关键字推断回退栈，并保留原字体名在栈首。
- **纸张配色 token 化**：单元格底色、文字色、网格线、填充柄描边统一走变量；深色纸张下白底压暗、深字提亮、网格线降对比，打印与导出由 `--mo-cell-*-plain` 还原原色。

### 设置

- 标尺、Excel 阅读模式、护眼模式默认关闭；旧存档中被写成开启的标尺会一次性迁移回隐藏，迁移只执行一次，之后用户手动开启不会被重置。

## 优化

- **缩放归位**：Word 与 Excel 的缩放统一移到右下角状态栏（比例下拉、减号、滑块、加号、适应宽度，40%–250%），工具栏只保留输出类按钮；状态栏左侧显示页码与总页数，只读文档仍可缩放。
- **工具栏图标**：颜色按钮改为 Excel 风格的「A + 颜色下划线」，填充改为油漆桶并保留当前填充色下划线。
- **表格工具合并**：移除独立的表格工具条，合并进主工具栏，减少一次悬浮切换。
- **表格选区**：改用半透明底色，去掉刺眼的蓝色描边。
- **图片编辑**：选中后 Delete / Backspace 直接删除、Esc 取消选中；拖动时帧尺寸与图片同步，不再出现空白大框；宽度钳制在正文栏宽内。
- **分页测量**：先按实测位置补齐制表符宽度再量高度；只含浮动图的段落保留一行最小高度，避免塌成 0 高。
- **状态栏**：显示软件名称。

## 修复

- **段内换行丢失**：三处根因都已收敛到结构化数据——粘贴多行文本时 `\n` 被压成空格；DOM 回写 runs 时忽略浏览器插入的 `DIV` / `P` 块级包裹；Tab 被写成 4 个空格。现在粘贴按行拆段并继承样式，块边界转为 `lineBreak`，`<br>`、图片、制表符各自成 run。
- **`w:t` 空白语义**：未声明 `xml:space="preserve"` 时首尾空白按 OOXML 规则丢弃；`w:t` 内的普通 CR/LF 只当空白，真正的换行仅由 `w:br` / `w:cr` 生成。
- **兼容旧写法**：支持 WPS / 旧版 Word 把控制节点直接挂在段落或超链接下的结构。
- **输入时整格变色**：普通点击单元格也会写入选区，导致整格铺灰底并随打印带出；现在同一单元格内的普通点击只定位光标，不产生灰底，跨格选择仍保留底色提示。
- **图片被拖出页面**：拖拽可把图片（尤其 8px 高的下划线图）拉成超出页面的巨块，现已钳制在正文栏宽内。
- **深色纸张白块**：单元格底色、填充柄、网格线在深色纸张下出现刺眼白框与高对比线条，已改为变量换算。
- **底纹整块丢失**：底纹解析此前只认对象键、不认 DOM 元素，打开文档时文字底纹、段落底纹与表格单元格底色可能全部读不到；现已兼容两种输入，并支持主题色填充 `w:themeFill`。
- **浮动图片段落塌陷**：只含浮动图的段落没有行内内容，分页时塌成 0 高，导致页面高度与实际不符。
- **固定行距被撑高**：制表符占位块的 `inline-block` 1em 高度会把固定行距的行盒撑高。
- **目录页码过期**：改动正文后目录页码不跟随，现由分页实时反查。

## 已知限制

- 通过非编辑器路径（批量合并、脚本调用）保存时，目录页码回落为第 1 页；Word / WPS 打开后按 `updateFields` 刷新域自动更正。
- macOS 仍为临时（ad-hoc）签名，未做 Apple 公证；Windows 安装包未做代码签名。
- 仅提供版本检查与提示，自动下载安装更新未做。
- Windows / Linux 实机的拖拽、打印与系统默认应用设置仍需在目标设备验收。
