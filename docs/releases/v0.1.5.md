# Mini Office 0.1.5

<!-- 功能：汇总 0.1.5-preview.2 之后的全部新增、优化与修复；时间：2026-10-29；作者：lq。 -->

0.1.5 正式版包含 0.1.5-preview.2 之后的全部改动：插件扩展系统、Word 样式库与排版增强、打印分页重写、默认应用与文件关联、版本更新提示完善，以及一批兼容性与体验修复。

## 新增功能

### 插件扩展系统

- **声明式插件包**：设置 → 扩展 → 插件可安装本地 `.moext` 包，支持启用、禁用与卸载。
- **官方插件市场**：从 GitHub 仓库索引拉取插件列表，支持刷新、一键安装、版本对比与「可更新 x → y」一键升级。
- **安装期校验**：清单字段、主题令牌白名单、主题对比度、zip 路径穿越、条目数与体积上限、SHA-256 完整性校验；含未支持贡献点的插件直接拒绝安装，避免「装了没效果」。
- **主题插件双层结构**：`--mo-*` 令牌控制配色，`toolbar / controlShape / density / titlebar` 枚举控制外壳形态；主题不能写入 `--mo-doc-*`，文档画布与打印输出不受主题影响。
- **经典菜单栏外观**：`classic-two-row` 变体在标题栏下渲染文件 / 编辑 / 视图 / 工具 / 帮助，还原 Office 2003 三段式结构。
- **功能插件 v1**：JSON 宏命令（8 个白名单操作，先校验后执行，不执行插件代码）与文档模板（包内 `.docx/.xlsx/.pptx`，安装期校验文件存在）。
- **插件快捷键**：必须带修饰键，与内置命令或其它插件冲突时标记原因并在命令面板禁用，而不是静默失效。
- **官方插件**：Office 365、WPS、Office 2003 三套主题与公文模板包。
- **可重现打包**：固定 zip 时间戳，重复打包哈希一致。

### Word 样式库

- **16 个预设样式**：正文、标题 1–4、标题、副标题、引用、题注、首行缩进、无间隔、强调引用、列表段落 / 项目符号 / 编号、等宽文本。
- **实时预览**：样式卡片用样式自身的字体、字号、粗细、颜色与对齐渲染样式名。
- **批量套用**：拖选多段一次套用，只产生一条撤销记录，套用后恢复选区可连续比较。
- **当前样式识别**：先读 `w:pStyle`，再按排版特征反推；工具栏显示「标题 1」等样式名。
- **本文档样式**：以当前段落格式新建样式、删除样式、清除格式；跨文档可保存 / 导入「我的样式集」，ID 冲突自动改名。
- **导入文档样式**：解析 `styles.xml` 中实际用到的段落样式并进入样式库。
- **写回 DOCX**：保存时按 CT_Style 顺序把用到的样式追加进 `styles.xml`，Word / WPS 打开仍显示样式名与标题层级。
- **快捷键**：⌘/Ctrl+⌥+1~4 套用标题 1–4，⌘/Ctrl+⇧+N 回到正文，⌘/Ctrl+⌥+M 打开段落对话框。

### Word 排版与编辑

- 新增**段落设置对话框**：缩进（首行 / 悬挂 / 左右）、段前段后间距、三种行距模式（多倍 / 固定值 / 最小值）精确输入，一次提交只产生一条撤销记录。
- 工具栏新增**中文字号组合框**（初号…八号与数字磅值并列，支持手动输入）与**行距组合框**（预设 + 固定值 / 最小值）。
- 新增**格式刷**：单击复制格式并套用一次，双击连续套用，Esc 退出。
- 新增快捷键：⌘/Ctrl+Enter 插入分页符、⇧+Enter 段内换行；回车分段继承样式关联，新段落仍属同一标题层级。

### 打印与分页

- 抽出 Word / Excel 共用的**打印分页基础设施**：页面盒尺寸与 `@page size` 对齐到标准纸张，打印时复位 `html/body` 高度与溢出、打印根节点回到普通流，解决只输出首屏内容、每页后多一张白纸、末尾固定空白页三类问题。
- **打印前置预览**：Word 与 Excel 打印前展示与应用内分页一致的全部分页；Excel 预览额外支持「适应窗口 / 实际大小」缩放切换。
- **方向切换**：Word 方向切换作用于整篇文档（含所有分节），多节混合方向时每页按自己所在节取纸张尺寸。
- **长表格跨页**：按实测行高切分并重复表头，续页只读，避免编辑落到错误的行上。
- **Excel 分页**：按真实行高与列宽切页，列宽超出可打印宽度时按列分页；跨页合并单元格按页裁剪并保留边框与底纹；页边距只由页面盒承担，不再二次压缩。

### 默认应用与文件关联

- 打包声明**七组文件关联**（docx/dotx/docm、xlsx/xltx/xlsm、pptx/potx/pptm、csv），系统双击与拖拽到图标可把路径交给应用。
- **Windows / Linux 冷启动**解析命令行参数入队；接入单实例插件，运行中再次打开文件转发到已有窗口，不再启动第二个进程争用恢复库。
- **首次启动提示**设置默认应用，全部已是默认时静默跳过；设置页新增常驻「默认应用」分区，菜单与命令面板可随时进入；窗口重新获得焦点自动刷新状态。

### 版本更新提示

- 启动后异步检查 GitHub Releases，不阻塞首屏；查到新版本弹一次提示，可「稍后提醒」，按版本号去重。
- 标题栏「更多」按钮显示小红点，结果持久化，重启后仍在；设置 → 关于显示更新状态并可手动检查。
- 自动检查 6 小时节流；仅当前为预览版时才提示预览版，正式版用户不会被 beta 打扰。

## 优化

- 设置窗口改为**左侧分类 + 右侧面板**的宽版布局，插件、默认应用、更新状态分区展示，避免长列表滚动。
- 字体：新增缓存与过期失效，读取字体文件内全部家族名作为别名（中英文名互通），缺失字体判断更准确；设置页可「重新扫描字体」，新装字体无需重启即可生效。
- 保存备份统一收敛到文档同级隐藏目录，并按份数淘汰最旧副本，不再在用户工作目录堆积同名副本。
- DOCX 序列化按 ECMA-376 固定顺序输出 `rPr`、`pPr`、`tcPr`、`tblPr`、`sectPr` 与 `CT_Anchor`，避免 Word 判定部件非法而拒绝打开；图形对象 ID 全文档唯一。
- 段落边框与最小值行距（`atLeast`）可完整往返保存。
- 幻灯片：双击进入文本编辑并把光标放到末尾，单击保持对象拖拽选中。
- 弹窗组件支持 `2xl` 宽度与内容区自管滚动，设置类长表单在 750px 小窗下仍可完整操作。

## 修复

- 修复 Word 多页文档打印只识别第一页、页数少于实际分页的问题。
- 修复 Excel 打印右侧列被裁掉、换行文本被页脚裁切、跨页合并单元格整块丢失的问题。
- 修复打印输出末尾固定多出一张空白页。
- 修复保存后 Word 提示「部件非法」以及样式名、标题层级丢失的问题。
- 修复 Windows 11 把文档拖到应用图标只启动软件、不打开文档；运行中重复打开会启动第二个进程。
- 修复更换文档默认字体后正文不跟随、中文名与英文名字体不匹配导致的误报缺失字体。
- 修复工具栏字号、行距下拉被横向滚动裁剪，以及点击后焦点落回正文的问题。

## 已知限制

- 插件运行时仅支持声明式插件（T1）；沙箱插件（T2）与原生 / 签名插件（T3）尚未实现，MCP 定位为 T3。
- 仅提供版本检查与提示，自动下载安装更新未做；macOS 仍为临时签名，未做公证。
- Windows / Linux 实机拖拽、打印与系统默认应用设置仍需在目标设备验收。
