# Mini Office 0.1.1

日期：2026-10-24；作者：lq。

- Word 新增页眉、页脚和常用页码设置，支持预览、起始页码及 DOCX 保存回读。
- 新增邮件合并与批量报告：XLSX/CSV 数据导入、模板字段、筛选勾选、逐份分页预览、批量打印及 DOCX/PDF/ZIP 输出。
- 完善长表格分页、重复表头和批量报告分节回读，保留每份报告独立编号与总页数。
- 补充 macOS 简体中文本地化声明，修正原生面板默认语言配置。
- 更正出品方为“非人类程序员出品”，加入微信公众号二维码，桌面状态栏显示 Mini Office。
- 增加手动 macOS 通用包工作流，同步更新 Windows/macOS 打包配置的版本号。
- 首页、设置及关于页统一从根包读取版本号。

本轮完成浏览器功能验收和自动测试。物理打印、Microsoft Word 客户端排版以及跨平台发行包仍需对应环境验收；详细支持范围见 [邮件合并说明](../word-mail-merge.md) 和 [页眉页脚说明](../word-header-footer.md)。
