# Mini Office 0.1.3

日期：2026-10-24；作者：lq。

## 功能与文档

- Excel 增加单元格格式弹窗、边框线型与颜色设置、公式引用点选/拖选和提交时括号补全。
- Excel 支持表头搜索与勾选筛选、多列条件组合、自定义单字段排序；筛选条件保存重开后可继续修改。
- Excel 支持图片插入、移动、等比例缩放、删除及 XLSX 保存回读，图片参与打印分页；CSV 不保存图片。
- 工作表支持双击原位改名、右键设置标签颜色，重命名维护跨表公式。
- README、兼容矩阵与实施完成度同步页眉页脚、邮件合并、表格编辑、PPTX 编辑/保存和安装包工作流的现状，并保留复杂格式与实机验收边界。
- 根包、桌面包、全部内部包、Cargo workspace、Cargo.lock 和 Tauri 统一为 0.1.3；界面版本继续从根包读取。
