# Word 表格编辑

更新：2026-10-19；作者：lq。

点击正文中的表格后显示“表格工具”。行高、列宽使用毫米输入，按 Enter 或移出输入框提交；行高为最小行高，内容较多时自动撑开。

## 已支持

- 原生文本跨格拖选、Shift + 点击扩展矩形选区，以及整表、整行、整列选择。
- 矩形合并单元格；遇到已有合并区域时自动扩展选区，保留全部段落、文字和图片。
- 将已合并的单元格拆回原有逻辑网格，内容保留在左上格。
- 上下插行、左右插列、删除选中行列及整表删除。编辑穿过合并区域时同步维护跨度。
- 拖动右边线调列宽、下边线调行高；一次拖动形成一次撤销记录。内部列边界移动时同步调整相邻列。
- 输入尺寸、平均行高、平均列宽及适应页宽。插列保持总宽度，数值调宽过大时收缩其他列以适应页面。
- 表格左中右对齐、单元格垂直对齐、底色、清除底色、所有边框与无边框。
- Tab / Shift + Tab 导航，末格 Tab 自动追加一行。
- 工具栏与右键菜单共用结构命令，支持撤销、重做及 DOCX 保存。
- 重复标题行标记保存为 DOCX 的 `tblHeader`，选中下方行时包含上方连续行。

## 当前边界

本轮覆盖常用基础编辑，不代表完整 Microsoft Word 功能对等。任意指定行列数的单元格拆分、画笔绘表、斜线边框、文字方向和内容自动适配尚未实现。当前分页仍将整张表视为一个块，跨页拆分长表及本地重复标题行渲染尚未实现；超高表格排版需要后续完善。浏览器验证不能代替 macOS WKWebView 和 Microsoft Word 实机验收。

## 验证

`tests/word-tables.test.ts` 覆盖矩形合并拆分、合并区域内增删行列、网格无重叠无空洞、尺寸与样式、页宽约束，以及整表合并后连续两次 DOCX 保存重开。完全被纵向合并覆盖的空行会保留，合并区域保存为网格总宽度。

真实 Chrome 验证覆盖 Shift 多选、合并拆分、尺寸输入、行列边线拖动、插列、撤销重做、整表选择、右键菜单与 Tab 追加行。
