# UI 设计规范与实现说明

> 目标：macOS 原生应用的轻盈感 + Office 高频操作效率 + 浏览器式多文件标签。
> 设计 Token 与组件已在 `packages/design-system`、`packages/ui` 中落地。

## 1. 视觉方向

- 默认取消高占屏 Ribbon，采用 **紧凑工具栏 + 选区浮动工具 + 右侧属性区 + 命令搜索**。
- 大面积留白、1px 分隔线、8–12px 圆角、低对比阴影。
- 默认跟随系统主题，支持浅色 / 深色 / 跟随系统三种模式。
- 默认主题色为「雾青」（`#2E7D72`），另提供远山蓝、紫藤、松针、陶土四套预设与自定义取色。
- macOS 桌面端可选开启原生毛玻璃效果：透明窗口 + `NSVisualEffectView` 磨砂材质。
- 中文界面使用系统可用字体：`-apple-system / PingFang SC / Microsoft YaHei / Noto Sans CJK`。
- 动效克制：120ms 状态反馈、180ms 弹层，不做夸张转场。

| `--mo-surface-2` | `#EEF2F9` | `#303641` | 次级面板、悬停 |

布局尺寸：标题栏 44px、标签栏 38px、编辑器工具栏 44px、公式栏 36px、状态栏 27px。

### 主题色配置

- 预设：雾青（默认）、远山蓝、紫藤、松针、陶土；每套都单独调过浅色与深色变体。
- 自定义：输入 `#RGB` / `#RRGGBB` 或使用系统取色器，运行时自动派生 hover、soft 与可读的文字色。
- 落地方式：只覆写 `--mo-accent`、`--mo-accent-hover`、`--mo-accent-soft`、`--mo-accent-ink`
  四个 CSS 变量，组件无需感知当前主题色；设置保存在 `localStorage`。
- 对比度：内置预设的强调色与按钮文字均达到 WCAG AA（≥ 4.5:1），深色模式使用更亮的强调色。

### macOS 毛玻璃

- 入口：设置 → 外观 → 毛玻璃效果；标题栏「更多」菜单中也有快捷开关。
- 原生层：`tauri.macos.conf.json` 将窗口设为 `transparent: true`，前端调用
  `Window.setEffects({ effects: [Effect.UnderWindowBackground] })`，启用 `NSVisualEffectView`
  的磨砂材质；`tauri.conf.json` 打开 `macOSPrivateApi`，权限为 `core:window:allow-set-effects`。
- Web 层：`data-vibrancy="on"` 时把 surface / canvas / line 等 Token 切换为半透明值，
  标题栏、标签栏、工具栏、侧栏与弹窗追加 `.mo-glass` 的 `backdrop-filter`，文档纸面保持不透明以保证可读性。
- 仅 macOS 桌面端显示入口；关闭时恢复不透明 Token，原生材质保留以便即时再次开启。

## 3. 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ TitleBar：品牌 / 当前文档 / 命令搜索 / 主题 / 设置 / 更多     │
├──────────────────────────────────────────────────────────────┤
│ TabBar：混合 Office 标签 / 未保存点 / 新建 / 打开             │
├──────────────────────────────────────────────────────────────┤
│ EditorToolbar（Word/Excel/PPT 上下文）                       │
│ FormulaBar（Excel）/ FindBar / SelectionToolbar               │
├──────────────────────────────────────────┬───────────────────┤
│ 内容画布：A4 页面 / 虚拟网格 / 幻灯片    │ 属性面板（可收起）│
│                                          │                   │
├──────────────────────────────────────────┴───────────────────┤
│ StatusBar：保存状态 / 模式 / 字数或单元格 / 兼容级别 / 快捷键│
└──────────────────────────────────────────────────────────────┘
```

### 首页

- 品牌 Hero：产品定位、打开文件、新建文档、拖拽提示、离线/本地/中文友好标签。
- 三张创建卡片：Word、Excel、PowerPoint。
- 内置模板：房屋租赁合同、费用报销单。
- 最近文件：搜索、快照来源、未保存标记、删除。
- 未保存恢复快照提醒条。
- 底部版本与快捷键入口。

### Word

![Word 编辑器](../screenshots/word-editor.png)

- A4 纸面居中，页与页之间 24px 间距；页边距、页眉页脚、页码按文档实际设置渲染。
- 工具栏：撤销/重做、字体、字号、加粗/斜体/下划线/删除线、文字色、突出显示、对齐、行距、缩进、列表、表格、图片、查找、属性、缩放、导出。
- 选中文字时使用浏览器原生选区 + 工具栏“就近”反馈；`execCommand` 与模型同步。
- 属性面板：纸张、方向、页边距、段前段后、行距、首行缩进、分页、统计、兼容性。
- 编辑模型：段落级 `contentEditable`，输入失焦后重新分页并保留焦点。
- 查找条：匹配计数、上一个/下一个、替换、全部替换、区分大小写。

### Excel

![Excel 编辑器](../screenshots/sheet-editor.png)

- 顶部操作栏下增加名称框与公式栏；列标题、行号固定；冻结覆盖层保持独立。
- 虚拟滚动只绘制可视单元格；选区/填充柄/合并单元格叠加在内容层。
- 单元格：字体、填充、边框、对齐、换行、数字格式、合并、冻结、筛选、排序、行列操作。
- 底栏：工作表标签、添加按钮、选区统计（求和/平均/计数）、工作表序号。
- 查找条与筛选对话框复用统一弹层样式。

### PowerPoint

![PPT 编辑器](../screenshots/slides-editor.png)

- 左侧缩略图列表（可收起），右侧 16:9/4:3 原始比例画布，自动适应窗口。
- 工具栏：上一页/下一页、页码、标题、比例、缩放百分比、备注、演示、导出、兼容性。
- 备注面板在下方可展开。
- 全屏演示：黑底、自适应缩放、左右点击区域、方向键/空格/Home/End、N 备注、Esc 退出。

## 4. 组件规范

- **Button**：primary / secondary / ghost / soft / danger；高度 32 / 28px。
- **IconButton**：28×28，active 使用 accent-soft 背景；所有图标按钮必须有 `aria-label`。
- **Select / Input**：28px 高、6px 圆角，focus 使用 3px accent 半透明外环。
- **Dialog**：12px 圆角、最大宽度 380/480/620/820；Esc 关闭、Tab 焦点循环、遮罩点击关闭。
- **Menu / Dropdown**：最小 190px，快捷键右对齐；危险项红色。
- **Toast**：右下角堆叠，最多 5 条，4.6s 自动消失；错误保留可关闭。
- **ColorField**：预设颜色 + 原生取色器 + 十六进制输入 + 清除。
- **Switch / SegmentedControl / Badge / ProgressBar / Kbd**：统一使用 Token。

## 5. 交互与可访问性

- 全局快捷键：`⌘/Ctrl+K` 命令面板、`⌘/Ctrl+S` 保存、`⇧⌘S` 另存、`⌘O` 打开、
  `⌘N` 新建、`⌘W` 关闭、`⌘P` 打印、`⌘F` 查找、`F5` 演示、`Esc` 退出。
- 命令面板支持 ↑↓/Enter/Esc 与分组（文件/编辑/视图/帮助/最近）。
- 标签支持拖拽重排、鼠标中键关闭、未保存圆点与关闭确认（保存/不保存/取消）。
- 焦点可见：`:focus-visible` 使用 2px accent 外环；拖拽区有明确遮罩与提示。
- 对比度：正文与背景符合 WCAG AA 目标；深色模式单独设定文本与强调色。
- 可访问名称：工具栏、对话框、标签关闭按钮、演示控制均有中文 `aria-label`。

## 6. 响应式与平台

- 桌面优先，最小窗口 960×620；首页在 1120px 内容宽度内响应式重排。
- 小高度时编辑器工具栏横向滚动，标签栏横向滚动，状态栏隐藏次要信息。
- 桌面窗口：Tauri 2；Web 模式用于开发与验证，不启动替代服务器。
- 未来移动端/HarmonyOS：所有系统能力经 `PlatformAdapter`，编辑器不直接依赖 Tauri。

## 7. 弹窗与演示模式（UI 精修）

### 弹窗

- 统一使用 Portal 渲染，遮罩加深至 `rgba(13,20,33,.44)`，面板为 16px 圆角与双层柔和阴影。
- 标题区固定为 16px 标题 + 12px 说明 + 36px 图标底；关闭按钮改为轻量圆形按钮，打开时不再自动聚焦关闭按钮。
- 内容区 `overflow-x: hidden`，长文件名、警告详情、能力名称支持截断/换行，避免横向溢出。
- 底部操作区使用半透明次级背景，与内容区通过 1px 分隔线分开。
- 兼容性报告改为“等级卡 + 提示卡 + 缺失字体 + 能力徽标 + 底部说明”的结构；能力使用带勾/叉的紧凑徽标，避免在小窗口中被裁切。
- 关闭确认改为统一的保存确认卡片：文档类型图标、文件名、未保存圆点、三个明确动作。

### 演示模式

- 浏览器模式通过 Fullscreen API 进入系统全屏；Tauri 模式通过 `setFullscreen(true)` 进入原生全屏。
- 退出演示（Esc、关闭按钮、标签关闭）会同步退出全屏。
- 全屏演示使用黑色舞台、等比缩放、滑动阴影、悬浮工具栏、备注浮层和底部快捷键提示。
- 若系统全屏不可用，自动降级为窗口内演示并提示用户。
