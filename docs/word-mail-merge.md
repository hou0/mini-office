# Word 邮件合并与批量报告

日期：2026-10-24；作者：lq。

## 如何完成一次批量打印

1. 打开或制作一份报告模板，排好标题、正文、表格、页眉页脚和页码。工具栏点击“邮件合并”。
2. 导入 XLSX / CSV，或选择已经打开的 Excel 工作簿。确认工作表和表头行；系统会建立本次数据快照，防止源表后续修改悄悄改变预览和输出。
3. 点击正文或表格单元格中的插入位置，再点击右侧的字段名。字段显示为 `«报告编号»` 等占位块，可以继续输入文字；保存模板时使用真正的 Word MERGEFIELD 域。
4. 点击“选择记录并预览报告”。可以搜索所有列，添加最多 5 个同时满足的条件，排序，再勾选要生成的记录。只输出当前筛选结果中勾选的记录。
5. 检查右侧真实分页预览，使用“上一份 / 下一份”切换记录，使用适合宽度或 50% / 75% / 100% 缩放检查文字和表格。
6. 选择“直接批量打印”，确认操作后会准备所有选中报告并打开系统打印面板；在系统面板中选择打印机、纸张、份数后执行打印。也可以先生成 PDF 再打印。

每份报告独立分页，页码从模板设置的起始值重新开始，总页数按该份报告计算。长表格根据实际行高拆页，连续的重复标题行会出现在每页。模板和源 Excel 不会被生成流程覆盖。

## 五种输出

| 输出方式 | 使用场景 |
| --- | --- |
| 直接批量打印 | 按筛选和勾选结果一次打印全部报告 |
| 合并为一个 PDF | 先核对整批报告，再保存或打印 |
| 合并为一个 Word 文档 | 每份报告独立成节，后续可继续编辑 |
| 每条记录一个 DOCX，打包 ZIP | 分别归档或交付可编辑报告 |
| 每条记录一个 PDF，打包 ZIP | 分别归档或交付定版报告 |

独立文件命名可使用 `{报告编号}_{姓名}`、`{单位}_{序号}`。系统附加顺序号，并清理文件名中的非法字符，避免重名覆盖。

生成过程显示进度并支持取消。取消后不保存本次未完成结果。若某条记录分页失败或资源加载失败，会显示源数据行号，本批不保存部分结果。

## 数据准备与校验

- 一行表头、一行一份报告；有值的列必须有唯一表头。数据区域不支持合并单元格。表头不是第一行时，可指定实际表头行。
- 空字段默认阻止输出。可明确勾选“允许空字段，按空白输出”；缺列、公式错误仍必须修正或取消选择对应记录。
- XLSX 使用数值显示格式，包括常见日期、金额、百分比以及纯零格式的补零编号。复杂自定义 Excel 数字格式沿用现有格式引擎的支持范围，应先检查预览。
- CSV 支持 UTF-8，无法按 UTF-8 解码时尝试 GB18030；支持逗号、制表符、分号分隔以及引号内换行。CSV 值按文本保留，不执行以等号开头的内容。
- 手机号、证件号、长编号应在 Excel 中存为文本。数值形式的长整数超过可保证精度时会报错，需核对原值后修正。
- 数字条件使用原始值比较，文字搜索使用显示值。公式应有可用的计算结果。
- 切换标签时保留本次数据快照、筛选和勾选；关闭应用后重新打开模板，需要重新选择数据源，不在模板中保存外部数据连接。

## 范围与限额

当前针对“一行数据对应一份固定结构报告”。不提供一对多重复明细、IF 条件段落、NEXT RECORD、标签/信封排版或自动发邮件。含多个节的文档可以打开查看、打印和保存；作为邮件合并模板时，当前要求使用单份、单节报告模板。

支持正文、表格字段，以及导入模板的默认页眉页脚字段。模板的首页不同、奇偶页不同、不同节纸张尺寸等复杂排版不在本次验收范围。

每个数据文件最多 50 MB、2000 条记录、200 个字段；每批最多 200 份。合并 PDF / 直接打印最多 500 页；逐份 ZIP 的原始文件总大小最多 200 MB。大批报告可按条件分批输出。这些为保护交互响应的上限，不代表所有复杂模板均已做满额压力验证。

超过整页高度的单一段落、单行或表头，以及需要跨页拆分的纵向合并表格，会提示调整模板，避免静默裁切。

## 实现与验证

实现包括：字段结构化模型与 MERGEFIELD 解析/保存、数据快照与格式化、筛选选择与错误阻断、共用静态渲染、长表分页、批量输出及分节回读。合并 Word 以 SECTIONPAGES 表示每份报告总页数，打开时请求更新分页域，生成结果移除原外部合并数据连接。

自动测试覆盖 CSV 长编号/换行、XLSX 日期金额、表头校验、多条件筛选、字段原子与字形保持、简单及复杂 MERGEFIELD、报告独立副本、合并 DOCX 分节与再次保存、页眉图片关系和常见补零格式。

浏览器验收使用专用测试文档与数据，检查了导入、插入字段、缺值阻断、筛选排序、实际文件输出和打印准备。PDF 输出使用真实页面渲染，需保留与当前 PDF 导出能力一致的限制：PDF 为页面图像，文本不可搜索。Microsoft Word 客户端的实际分页、macOS 原生打印面板及物理打印机仍需实机验收。
