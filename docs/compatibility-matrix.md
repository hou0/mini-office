# 兼容性矩阵（0.1.3）

<!-- 功能：按当前源码同步兼容性与保存边界；时间：2026-10-24；作者：lq。 -->

> 兼容等级：**L0** 无法打开 · **L1** 可预览/只读 · **L2** 可编辑但需另存副本 · **L3** 可验证安全往返保存
>
> “可预览”不等于“可往返保存”。本矩阵以 Mini Office 0.1.3 的实际实现为准，
> 真实样例回归见 `tests/office-fixtures.test.ts` 与 `tests/xlsx.test.ts`。

## 1. DOCX（Word）

| 特性 | 读取 | 编辑 | 保存 | 级别/备注 |
|---|---|---|---|---|
| 段落、文字、字体、字号、颜色、加粗/斜体/下划线/删除线 | ✅ | ✅ | ✅ | L3 |
| 对齐、左右缩进、首行缩进/悬挂、段前段后、行距 | ✅ | ✅ | ✅ | L3 |
| 页面尺寸、方向、页边距 | ✅ | ✅ | ✅ | A4/A3/A5/Letter/B5 与自定义 |
| 页眉/页脚、页码字段（PAGE/NUMPAGES） | ✅ | 文字、预设页码、起始页码 | ✅ | 复杂图片/表格/特殊域保留；首页不同、奇偶页与复杂分节预览有局限，见页眉页脚说明 |
| 表格、单元格合并、底纹、边框、垂直对齐 | ✅ | 合并/拆分、行列增删、尺寸与样式 | ✅ | 支持长表分页及重复表头；复杂跨页合并仍需 Office 复核 |
| 内嵌图片（PNG/JPEG/GIF/WebP/SVG） | ✅ | 插入/删除 | ✅ | 新增图片写入 `word/media` 与关系 |
| 分页符、段前分页 | ✅ | 插入 | ✅ | |
| 查找替换 | ✅ | ✅ | — | 替换只修改文本 run，不破坏样式 |
| 列表/编号（解析 `numbering.xml`） | ✅ | 新建文本列表（标记 + 缩进） | ✅ | 原始编号引用与 `numbering.xml` 保留 |
| 修订记录（`w:ins`/`w:del`） | ✅ 显示插入内容 | ❌ | L2 另存 | 兼容性警告；建议在 Word 中处理修订 |
| 批注 | 显示正文 | ❌ | 原批注部件保留 | L2 另存，锚点可能丢失 |
| 内容控件（`w:sdt`） | ✅ 作为文本 | ❌ | L2 另存 | |
| 嵌入对象/`w:object` | 保留部件 | ❌ | L2 另存 | 不在页面中渲染 |
| 超链接 | 文本可见 | ❌（作为普通文本） | 关系保留但生成的主文档不写回超链接 | 当前限制 |
| VBA 宏（`.docm`） | 可解析正文 | ❌ | 强制只读 | L1，不执行宏 |
| 数字签名 | 可解析正文 | ❌ | 强制只读 | L1，避免签名失效 |
| 旧版 `.doc`（OLE） | ❌ | ❌ | ❌ | L0，提示另存 DOCX |

## 2. XLSX（Excel）/ CSV

| 特性 | 读取 | 编辑 | 保存 | 级别/备注 |
|---|---|---|---|---|
| 单元格值、文本/数字/布尔/错误 | ✅ | ✅ | ✅ | L3 |
| 共享字符串、内联字符串 | ✅ | ✅ | ✅ | 保存统一使用 `inlineStr` |
| 字体、字号、颜色、加粗/斜体/下划线、填充、对齐、自动换行 | ✅ | ✅ | ✅ | 样式重建为 `styles.xml` |
| 数字格式（数字/货币/百分比/千分位/日期/时间/文本） | ✅ | ✅ | ✅ | 内置 + 自定义 numFmt |
| 边框 | ✅ | 预设、线型/颜色、格式弹窗 | ✅ | 外框/内部框线按选区边界应用 |
| 合并单元格 | ✅ | ✅ | ✅ | |
| 冻结窗格 | ✅ | ✅ | ✅ | 独立覆盖层渲染 |
| 列宽、行高、隐藏行/列 | ✅ | 拖拽调整 | ✅ | |
| 工作表增删、重命名、切换、标签颜色 | ✅ | 原位改名、标签颜色、增删/切换 | ✅ | 改名同步维护跨表引用 |
| 浮动图片（PNG/JPEG/GIF） | ✅ | 插入/移动/等比例缩放/删除 | ✅ | 支持常用图片锚点与打印；复杂绘图效果需复核 |
| 自动筛选 | ✅ | 表头搜索/勾选、多列组合、逐列清除 | ✅ | 保留筛选条件和手动隐藏行；表头始终可见 |
| 排序 | ✅ | 列升降序、自定义单字段排序 | ✅ | 结果保存；移动整行并维护公式，空白值置后 |
| 复制/粘贴/填充柄 | ✅ | ✅ | — | 公式相对引用会平移 |
| 撤销/重做 | — | ✅ | — | 模型快照，最多 60 步 |
| 公式：算术、比较、字符串、区域、跨表、绝对/相对引用 | ✅ | ✅ | ✅ | 循环引用返回 `#CIRC!` |
| 公式：SUM/AVERAGE/COUNT/MAX/MIN/ROUND/IF/IFS/IFERROR/VLOOKUP/XLOOKUP/INDEX/MATCH/SUMIF(S)/COUNTIF(S)/文本/日期等 60+ | ✅ | ✅ | ✅ | 不支持 VBA、动态数组与 Power Query |
| 共享公式（shared formula） | ✅ | ✅ | 保存为普通公式 | 解析时展开并平移 |
| 日期系统 1900/1904 | ✅ | — | ✅ | 保留 `date1904` |
| 条件格式 | 保留部件 | ❌ | 保留规则 | L2 另存；不渲染效果 |
| 图表 | 保留部件 | ❌ | 保留部件 | L2 另存；编辑工作表后需重新核对 |
| 数据透视表 | 保留部件 | ❌ | 保留部件 | L2 另存；不刷新 |
| 批注 | 保留部件 | ❌ | 保留部件 | L2 另存 |
| 外部工作簿链接 | 警告 | ❌ | 保留关系 | 不自动加载/刷新 |
| VBA 宏（`.xlsm`） | ✅ 值/公式 | ❌ | 强制只读 | L1，不执行宏 |
| CSV | ✅ | ✅ | ✅ | L3；仅文本/数值，公式保存为计算结果 |
| 旧版 `.xls`（OLE） | ❌ | ❌ | ❌ | L0 |

## 3. PPTX（PowerPoint）

> PPTX 基础内容可编辑，打开原文件保持不变，首次保存会另存副本；复杂效果保留原始部件并在兼容性报告中提示。

| 特性 | 读取/渲染 | 编辑 | 备注 |
|---|---|---|---|
| 16:9 / 4:3 / 自定义尺寸 | ✅ | — | 原始比例 |
| 主题色、主题字体、母版/版式继承 | ✅ | — | 占位符坐标与文本样式继承 |
| 文本框、标题、正文、项目符号 | ✅ | ✅ | 段落/run 级字体、颜色、对齐、行距；编辑后安全回写 |
| 形状（矩形、圆角、椭圆、三角、菱形、箭头、星形等） | ✅ | — | CSS 几何近似 |
| 图片、裁剪、旋转/翻转 | ✅ | — | `a:srcRect` 裁剪 |
| 表格、单元格填充、合并 | ✅ | 表格文字 | 表格结构编辑仍有限 |
| 组合（group）与坐标变换 | ✅ | — | |
| 演讲者备注 | ✅ | ✅ | 侧栏与演示 N 键 |
| 缩略图列表、系统级全屏演示、键鼠换页 | ✅ | — | F5/方向键/空格/Home/End/Esc；浏览器 Fullscreen API / Tauri 原生全屏 |
| 动画 / 切换 | 忽略 | — | 显示兼容提示，静态预览 |
| 视频 / 音频 | 不播放 | — | 显示兼容提示 |
| 图表 / SmartArt / 嵌入对象 | 不渲染 | — | 显示兼容提示 |
| 对象移动与键盘缩放 | ✅ | ✅ | 基础布局调整 |
| 保存/新建、页面增删复制 | ✅ | ✅ | 首次保存另存副本，保留复杂原始部件 |

## 4. 跨格式与平台特性

| 特性 | Web | Tauri 桌面 | 备注 |
|---|---|---|---|
| 文件选择 | File System Access / `<input>` | 原生对话框 | 用户显式授权路径 |
| 保存/另存 | File System Access / 下载 | 原生对话框 + 原子写入 | Tauri 写入前校验 OOXML 容器 |
| 拖拽打开 | ✅ | ✅（Tauri 拖放事件） | 支持 DOCX/XLSX/PPTX/CSV |
| 最近文件 / 自动恢复 | IndexedDB | IndexedDB + 应用数据目录/SQLite | 离线保存 |
| 字体检测 | Canvas 度量探测 | Rust 字体目录 + `ttf-parser` | 缺失时提示替代 |
| 主题/强调色 | 浅/深/跟随系统，5 套预设 + 自定义 | 同 Web + 原生毛玻璃 | 对比度测试；毛玻璃需 macOS 实机验收 |
| 窗口拖动/最大化 | — | 标题栏/标签栏空白区拖动、双击最大化 | Tauri 权限已声明 |
| PDF 导出 | ✅（Canvas + jsPDF） | ✅（同前端） | LibreOffice 仅 PoC |
| 打印 | 浏览器打印 | 原生打印面板 | Word/Excel 使用分页 DOM；Tauri `print_window` |
| 多文件标签 / 命令面板 / 主题 | ✅ | ✅ | |

## 6. 不在 V1 范围

- 云端协作、账号体系、AI 助手。
- VBA / 宏执行。
- 复杂 PPT 动画、视频播放。
- 完整数据透视表、Power Query、外部数据库连接。
- 复杂域、内容控件、数字签名编辑；邮件合并与批量报告已支持，见 [使用说明](word-mail-merge.md)。
- 移动端与 HarmonyOS NEXT（仅保留适配边界，未实现）。
