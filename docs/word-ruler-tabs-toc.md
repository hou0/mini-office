# Word 标尺、制表位与目录

<!-- 功能：说明标尺、制表位、目录与段内换行的实现边界与使用方式；时间：2026-10-30；作者：lq。 -->

> 对应版本：0.1.6 排版补齐 ｜ 相关代码：`packages/editor-word/src/{WordRuler,tab-stops,toc,parse,serialize}.ts`

Word 文档里「甲方：______」这类填空行、合同落款右对齐、页眉横线，本质上都靠**制表位**排版；长文档的导航靠**目录**。这两块此前在 Mini Office 里是空的——按 Tab 只会插入空格，目录只能手敲点线和页码，改动正文后页码不会跟随。本文说明补齐后的行为与已知边界。

## 1. 标尺

标尺**默认隐藏**，与 Word / WPS 一致（原版默认也不显示标尺，绝大多数人日常写作并不需要它）。需要精确调缩进或摆制表位时再打开，三个入口：

- Word 工具栏「标尺」按钮
- 菜单栏「视图 → 标尺」（经典菜单栏外观下）
- 命令面板（⌘/Ctrl+K）搜「标尺」

设置里也能开关：设置 → 外观 → Word 标尺。开关状态会记住，下次启动保持。

打开后：

- 正文上方显示横向标尺，刻度按厘米标注，页面左右页边距用底色区分。
- 首行缩进、左缩进、右缩进三个三角可直接拖动；拖动过程中所有位置在**未缩放坐标系**里计算，缩放只影响显示，因此 50% 缩放与 200% 缩放拖到的是同一个值。
- 标尺空白处单击新增制表位，拖动制表位调整位置，双击或拖出标尺删除。
- 拖动产生的撤销记录按拖动过程合并为一条，不会出现「拖一次要按十次撤销」。
- 打印与 PDF 导出永远不包含标尺。

## 2. 制表位

| 能力 | 说明 |
|---|---|
| 对齐方式 | 左对齐、居中、右对齐、小数点对齐 |
| 前导符 | 无、点线（dot）、虚线（hyphen）、下划线（underscore）、中点线、粗线 |
| 正文输入 | 光标处按 Tab 插入结构化制表符（不是空格），⇧+Tab 交给焦点导航 |
| 默认间距 | 文档级 `w:defaultTabStop`，缺省 720 twips（48px，即 0.5 英寸） |
| 读写 | 解析与保存 `w:tabs` / `w:tab`，写在 `w:pPr` 的 `w:shd` 之后、`w:spacing` 之前，符合 CT_PPr 顺序 |

实现要点：浏览器无法用 CSS 表达「跳到下一个制表位」，因此渲染时先输出**零宽占位块**，等浏览器排版完成后由 `applyTabStops()` 实测每个制表符的横向位置，再补上宽度与前导符边框。屏幕分页 DOM 与离屏测量容器跑同一套函数，所以分页高度与屏幕显示不会互相打架。

## 3. 目录

- 工具栏「插入目录」在光标处插入目录段落，默认采集 1–3 级标题。
- 标题判定与 Word 一致：先看段落大纲级别（`w:outlineLvl`），再看内置样式 ID（`HeadingN` / `标题N`），**不依赖自定义样式的显示名**，避免样式改名后目录突然变空。
- 条目文本取段落纯文本，图片与域占位不计入；制表符归一为空格。
- 页码由分页结果实时反查，并叠加节的起始页码（`w:pageNumberStart`），因此增删正文后页码自动跟随，不需要手动「更新域」。
- 点击目录条目跳转到对应标题所在页。
- 保存时写回真正的 TOC 域（`fldChar begin` / `instrText " TOC \o "1-N" \h \z \u "` / `separate` / 条目 / `end`），并在 `settings.xml` 写入 `<w:updateFields w:val="true"/>`。

**已知边界**：保存 docx 时的条目页码来自编辑器实测分页；若通过非编辑器路径（如批量合并、脚本调用）保存，页码回落为第 1 页，Word / WPS 打开时会因 `updateFields` 提示刷新域后自动更正。

## 4. 段内换行与粘贴

同一轮修复了换行丢失问题，根因有三处，都已收敛到结构化数据：

1. 粘贴多行文本时曾把 `\n` 压成空格 —— 现在按行拆成多个段落，首行沿用原段落，后续行插入新段落并继承样式。
2. DOM 回写 runs 时忽略浏览器插入的 `DIV` / `P` 包裹 —— 现在块边界转成 `lineBreak`，`<br>` 与图片、制表符各自成 run，且首个块级包裹前不会补多余换行。
3. Tab 曾写成 4 个空格 —— 现在写结构化制表符，保存为 `w:tab`。

## 5. 护眼模式与阅读模式

- **护眼模式**：标题栏眼睛按钮或 设置 → 外观 切换，只切 `data-eyecare`，配色集中在 `tokens.css`（米黄纸色、低蓝光）。导出 PDF 与打印时强制回白纸，交付文件不会被米黄底色污染。
- **阅读模式**：Excel 工具栏「阅读模式」开启后，当前单元格所在行列在网格内叠加浅色参考带，并点亮对应行/列表头，方便核对长表格；关闭后不渲染任何额外节点。
