# Word 页眉、页脚与页码

日期：2026-10-24；作者：lq。

## 使用

工具栏点击“页眉、页脚与页码”，或双击页面上、下方的留白区域。

切换“页眉 / 页脚”，输入文字，或者选择常用页码样式：纯数字、横线包围、第 X 页、第 X 页 / 共 Y 页、X / Y、Page X of Y。可以在文字光标处插入当前页码与总页数，支持多行文字、左/中/右对齐、字号、距纸边距离及起始页码。总页数表示实际页数，例如文档共 2 页、起始页码为 5，显示第 5、6 页，共 2 页。

右侧预览可前后翻页；应用前不修改文档。应用后所有默认页眉页脚同步变化，可撤销/重做。长内容按页面宽度估算换行并扩展正文页边距；内容过多挤占正文时会提示减少内容。具体位置以应用后的页面为准。

清空只清除当前区域，另一侧保留。导入区域若含图片、表格或特殊域，会保留原内容并禁止直接改写；用户可主动清空后换成文字/页码。

## 保存与范围

- DOCX 写入独立 header/footer 部件、关系与内容类型，使用 PAGE / NUMPAGES 动态域，保留起始页码。
- 未编辑的导入页眉页脚仍沿用源部件；编辑仅替换默认引用，保留源文档的其他引用和媒体。
- 本次提供统一默认页眉页脚；不提供首页不同、奇偶页不同、分节独立编号、罗马数字页码或图片/表格页眉编辑。原文件含上述变体时，当前编辑预览不能完整体现分节/首页/奇偶规则。
- 打印和 PDF 使用应用后的页面 DOM。浏览器打印布局可校验，桌面 WKWebView、Microsoft Word 客户端及物理打印机仍需单独验收。

## 验证

自动测试覆盖预设动态域、转义、多行、字号/对齐状态、新建 DOCX、起始页码、修改真实合同并保留页眉/图片，以及再次清空后重开。浏览器检查覆盖多页预览、连续输入、取消、应用、撤销与重做。
